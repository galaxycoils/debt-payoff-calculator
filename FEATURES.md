# Addictive & Viral Feature Roadmap

Goal: Maximize time-on-site, return visits, and shares so AdSense revenue grows. Everything stays client-side.

## Implemented
- Side-by-side Snowball vs Avalanche comparison with winner banner and interest savings
- Dual-line charts
- LocalStorage for debts + extra payment
- Share button (Web Share API / clipboard)
- Month-by-month schedule
- Clean monetization placeholder after results

## High-Priority Next (Daily Automation Focus)
1. **Live extra-payment slider** – drag and results update instantly (biggest engagement lift)
2. **Progress % bar** – “You are X% of the way to debt-free”
3. **Shareable result image** (canvas) with debt-free date + dollars saved
4. **One-time Snowflake payments**
5. **Debt kill-order timeline** (which debt dies in which month)
6. **Local history of last calculations** so users can re-run scenarios
7. **“What if +$50 / +$100 / +$200” quick buttons**
8. **Near-debt-free celebration** when months remaining is low
9. **Copy result summary** for Reddit / social
10. Supporting SEO pages for long-tail traffic

## Why these features
Research on top debt tools (Undebt.it, Debt Payoff Planner, Unbury.me, etc.) and retention patterns shows:
- Instant feedback loops (sliders, live recalculation) keep users playing with numbers
- Visual progress and “wins” create emotional investment
- Shareable artifacts drive organic traffic
- Scenario comparison increases session depth → more ad impressions

All features must remain 100% client-side and free to host.
