# Debt Payoff Calculator

Free, private, client-side debt snowball / avalanche payoff calculator and visualizer.

- Everything runs in your browser — your data never leaves your device
- Compare Snowball vs Avalanche side-by-side
- Toggle biweekly payments and compare a consolidation loan vs staying put
- Live charts, month-by-month schedule, interest savings
- Built for Cloudflare Pages (free hosting + custom domain)
- Monetization-ready (AdSense + finance affiliates)

## Live Demo
https://debt-payoff-calculator-six.vercel.app

## How to use
1. Add your debts (name, balance, APR, minimum payment)
2. Set any extra monthly payment (or toggle biweekly)
3. Choose strategy or compare both
4. Optionally compare a consolidation loan or balance-transfer offer
5. See your exact debt-free date and savings instantly

## Tech Stack
- Pure HTML + Tailwind CSS (CDN) + vanilla JS + Chart.js
- No backend required
- LocalStorage for saving your debts between visits
